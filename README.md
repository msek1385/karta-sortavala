# Наружное освещение г. Сортавала, этап 2

Интерактивная карта опор освещения и ТП/КТП, от которых они запитаны.

- `index.html` — карта (открывается через GitHub Pages).
- `data/map.json` — данные карты, зашифрованные общим паролем (PBKDF2-SHA256 + AES-GCM). Карта открывается только после ввода пароля; без него файл не прочитать. Редакторы меняют данные прямо на карте кнопкой «Сохранить на сайт» (каждое сохранение — отдельный коммит) и могут сменить пароль кнопкой «Сменить пароль карты».
- `data/nets.json` — трассы тепловых сетей (из чертежа Н13-251), зашифрованные тем же паролем. При смене пароля карты перешифровываются вместе с ней.

Редакторы — участники этого репозитория с правом записи (Settings → Collaborators). Остальные видят карту только для просмотра.
