# Наружное освещение г. Сортавала, этап 2

Интерактивная карта опор освещения и ТП/КТП, от которых они запитаны.

- `index.html` — карта (открывается через GitHub Pages).
- `data/map.json` — данные карты. Их меняют редакторы прямо на карте кнопкой «Сохранить на сайт»; каждое сохранение — отдельный коммит.

Редакторы — участники этого репозитория с правом записи (Settings → Collaborators). Остальные видят карту только для просмотра.
